# PandAI — archive

A game-AI library for [Panda3D](https://www.panda3d.org/) — steering, flocking, obstacle
avoidance, navmesh pathfinding — built at Carnegie Mellon's Entertainment Technology
Center. Both project sites are gone; this mirror rebuilds them, with every recoverable
release and demo.
