Arrival

'Arrival' is a behavior where an AICharacter slows down before approaching its target destination.


Arrival





In PandAI, arrival is defined as :

aiBehaviors.arrival(double distance)

where 

Distance is the distance in the seek/pursue from the target at which to start the arrival from.


The velocity at which the AICharacter seeks is determined when you first create your AICharacter object using the AICharacter constructor.
