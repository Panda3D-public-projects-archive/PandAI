Download



Now, PandAI comes as a part of Panda3D 1.7.0 and so you don't need to download anything to get it setup !

Until recently, PandAI needed to be downloaded as a dll and steps required to integrate it into Panda3D.


Any further updates or necessary downloads with respect to PandAI will be posted here.



Source Codes ( Attached below ) :

1. Pandai_v1.0_src.zip     - This is the entire source code of PandAI + Doxygen documentation.  (Open Source)

2. meshgen_v1.0_src.zip  - This is the entire source code of the mesh generator for Maya and Max  (Open Source)

3. meshgen_v1.0_exec.zip   -  This is the mesh generation tool (Windows version) for Maya and Max users  (Open Source)

4. BlenderMeshGen.zip   -  This is the python source code for the Blender mesh generator + few samples  (Open Source)
