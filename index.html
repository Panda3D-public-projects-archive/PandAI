PandAI

A game-AI library for Panda3D — steering, flocking, obstacle avoidance, navmesh pathfinding — built at Carnegie Mellon's Entertainment Technology Center. Both project sites are gone; this mirror rebuilds them, with every recoverable release and demo.

The wiki →

The later Google Sites documentation (captured 2020): getting started, every steering behaviour, pathfinding and the mesh generator. 22 pages, with the original demo videos embedded.

The 2010 ETC site →

The original project site: team, research write-ups, gallery, AI types and the first-generation downloads. 8 pages.

Downloads →

28 recovered archives — library releases v0.2 through v1.0, source drops, the Blender mesh generator and every sample project.

Community field notes →

What the documentation doesn't tell you: known bugs and their workarounds, how the navmesh pipeline actually behaves, and design notes from the authors — gathered from fifteen years of forum and Discord threads.

Source in this repo →

Unpacked and browsable: the 12 Python examples, the mesh generator C++ source and the Blender navmesh exporter.

Demo videos →

All 25 demo reels the two sites embedded, indexed with direct links. Hosted on YouTube, not mirrored here — every one was still reachable when this archive was assembled.

Source included in this repository

PathWhat it is
examples/ Twelve runnable Python samples — seek, flee, pursue, evade, wander, flock, path follow, static and dynamic obstacle avoidance, and uneven-terrain pathfinding — with their models and textures. Updated to Python 3 / modern ShowBase style.
meshgen_v1.0_src/ C++ source for the standalone navigation-mesh generator (aiMeshGenerator, meshNode).
BlenderMeshGen/ Python navmesh exporter driven from Blender geometry; emits the navmesh.csv the pathfinder consumes. Includes test .blend/.egg planes.
archive/raw/ The verbatim archived HTML both mirrors were rebuilt from, kept unmodified.
